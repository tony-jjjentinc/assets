# Shared Assets Repository

This repository hosts shared assets (fonts, custom Bootstrap CSS themes, and SVG images/logos) for Google Apps Script Web Applications via GitHub Pages.

For detailed documentation, please refer to the files in the `docs/` directory:
- [Overview](docs/OVERVIEW.md) - Project structure and purpose.
- [Setup](docs/SETUP.md) - Instructions for local development and building assets.
- [Reference](docs/REFERENCE.md) - Instructions for integrating these assets into your Google Apps Script projects.

Bootstrap 5 Custom Color CDN

GitHub Pages-hosted CSS overrides for unified styling across Google Apps Script web apps.

Quick Start

Add these three lines to your Google Apps Script HTML <head>:

<!-- 1. Bootstrap 5 CSS -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

<!-- 2. Base style overrides -->
<link href="https://{username}.github.io/assets/css/base.css" rel="stylesheet">

<!-- 3. Department color (choose one) -->
<link href="https://{username}.github.io/assets/css/colors/gmo/gmo.css" rel="stylesheet">

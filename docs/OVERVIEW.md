# Architecture Overview

## What This Project Does

This project provides a set of static CSS files hosted via GitHub Pages that override Bootstrap 5's default styling and primary color. It acts as a lightweight CDN for web applications deployed through Google Apps Script.

## Architecture

```
┌──────────────────────────────────────────────────────────────┐
│  Google Apps Script HTML Page                                │
│                                                              │
│  ┌─────────────┐  ┌─────────────┐  ┌──────────────────────┐ │
│  │ Bootstrap 5  │→ │  base.css   │→ │  colors/{dept}.css   │ │
│  │   CDN CSS    │  │  (GitHub    │  │  (GitHub Pages CDN)  │ │
│  │              │  │  Pages CDN) │  │                      │ │
│  └─────────────┘  └─────────────┘  └──────────────────────┘ │
│         ↓                ↓                    ↓              │
│  Default Bootstrap   Custom fonts,     Department-specific  │
│  components          border-radius,    primary color        │
│                      shadows           override             │
└──────────────────────────────────────────────────────────────┘
```

## Design Principles

### 1. CSS-Only Overrides (No Build Tools)
The project uses plain CSS files — no Sass compilation, no npm, no bundler. Files are served directly via GitHub Pages as-is.

### 2. Load Order Dependent
CSS specificity and the cascade are used to override Bootstrap defaults. The load order **must** be:
1. Bootstrap 5 CSS (from jsDelivr CDN)
2. `base.css` (fonts, shadows, component refinements)
3. `colors/{dept}/{file}.css` (primary color override)

### 3. Two-Layer Override System
- **`base.css`** — Applies universally. Changes fonts (Inter), reduces border-radius, adds shadows, and refines component styles. Does NOT change any colors.
- **Color files** — Each file overrides Bootstrap's default blue primary color with a department-specific color. Only ONE color file should be loaded per page.

### 4. Separation of Concerns
Base styling and color are independent. You can update `base.css` without touching any color files, and vice versa. Any color file works with the same `base.css`.

## Why Not Just Use Sass?

Google Apps Script HTML files cannot run build tools. The CSS must be served as pre-built static files. While Bootstrap's Sass source is the "official" way to customize, our use case requires:
- Pre-built CSS files accessible via URL
- No build step in the consuming application
- Simple `<link>` tag imports

## How Color Overrides Work

Bootstrap 5.3+ compiles its Sass variables into hardcoded CSS values at build time. For example, `.btn-primary` gets `background-color: #0d6efd` baked in — it does NOT reference `var(--bs-primary)` at runtime.

This means overriding `--bs-primary` on `:root` alone is **insufficient**. Our color files override:

1. **Root-level CSS variables** — `--bs-primary`, `--bs-primary-rgb`, `--bs-link-color`, etc. These affect utility classes (`.text-primary`, `.bg-primary`).
2. **Component-scoped CSS variables** — Each component (`.btn-primary`, `.alert-primary`, `.pagination`, etc.) has its own set of CSS variables that must be individually overridden.
3. **Direct property overrides** — Some components (form checkboxes, range inputs) use direct CSS properties rather than variables.
4. **Dark mode overrides** — A `[data-bs-theme="dark"]` block overrides Bootstrap 5.3's dark-mode-specific subtle colors (text emphasis, background, border) to maintain the department color in dark mode.

## Color Math

Derived colors (hover states, subtle backgrounds, text emphasis) are calculated using the same formulas Bootstrap's Sass uses:

| Derived Color | Formula | Purpose |
|---|---|---|
| Hover | `shade-color(primary, 20%)` | Button hover, link hover |
| Active | `shade-color(primary, 25%)` | Button active state |
| Active border | `shade-color(primary, 30%)` | Button active border |
| Text emphasis | `shade-color(primary, 60%)` | Alert text, list group text |
| BG subtle | `tint-color(primary, 80%)` | Alert background, accordion active bg |
| Border subtle | `tint-color(primary, 60%)` | Alert border, table border |
| Focus border | `tint-color(primary, 50%)` | Input focus border |

Where:
- `shade-color(color, weight)` = mix color with black by weight percentage
- `tint-color(color, weight)` = mix color with white by weight percentage

## Text Contrast

The generator script automatically determines whether to use white (`#fff`) or dark (`#212529`) text on the primary color background, using WCAG 2.0 contrast ratio calculations. This ensures readability across all department colors, including light colors like Admin's gold (`#FFD700`).

## File Generation

The 72 color CSS files are generated by `scripts/generate_colors.py`, which:
1. Reads `css/colors/_template.css`
2. Computes all derived color values from each department's base hex color
3. Replaces `{{PLACEHOLDER}}` tokens with computed values
4. Writes the output CSS files

This script is a **development tool only** — it is not needed at runtime and is not part of the CDN output.
